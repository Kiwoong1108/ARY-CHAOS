# 혼돈 윷놀이 (ARY-CHAOS)

진짜 윷놀이 + 칼바람식 증강 + 능력치 모루. 친구랑 실시간으로 하는 웹게임.

## 플레이
GitHub Pages 주소로 접속 → 닉네임 입력 → 방 만들기 / 참가

- **온라인**: 공개방(목록에서 찾기, 코드 P01~P24) 또는 비공개방(4글자 코드)
- **같은 컴퓨터**: 같은 브라우저 탭끼리 연결
- **로컬**: 봇이랑 하거나 한 기기로 돌려하기

## 멀티 구조
- PeerJS 1.5.4 (unpkg)로 처음 연결만 공용 서버 사용, 이후 브라우저끼리 P2P
- 방장이 게임 상태를 관리, 최대 4명
- 나간 사람은 봇이 대신 플레이

## 룰 요약
- 말 4개, 도·개·걸·윷·모·빽도, 업기·잡기·지름길
- 증강: 시작 + 3·6·9턴 (실버/골드/프리즘)
- 모루: 10턴부터 2턴마다 (능력치 증강으로도 획득)
